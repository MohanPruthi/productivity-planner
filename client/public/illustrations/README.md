# Illustrations

Each slot uses the bundled SVG (`welcome.svg` etc.). To replace one, drop a PNG with the same name here (e.g. `welcome.png`); a PNG always wins over the SVG.

| File | Where it shows |
|---|---|
| `welcome` | Login and sign-up pages |
| `tasks-empty` | Dashboard, no tasks for the day |
| `dsa-empty` | Dashboard and DSA page, nothing logged |
| `notes-empty` | Notes, no notes yet |
| `contacts-empty` | Directory, no contacts |

## Generating PNG replacements in ChatGPT (optional)

Use **one chat** for all five so the style stays consistent. Paste the style block first, then each subject one at a time. Ask for a **transparent background PNG**. Download each image and save it under the name above.

### Style block (paste first)

> I'm making a set of 5 small illustrations for a dark-mode personal planner app. Keep every image in the exact same style:
> minimal flat vector illustration, simple geometric shapes, thick rounded strokes, generous empty space, one centered subject.
> Palette only: indigo #6366F1, soft lavender #A5B4FC, warm amber #FFA116 as a small accent, off-white #E6E7EB.
> No text, no letters, no gradients, no drop shadows, no glow, no background scene.
> Transparent background, square 1024×1024 PNG. It must read clearly on a near-black (#0F1117) background.
> Reply "ready" and wait for the subjects.

### Subjects (send one at a time)

1. **welcome.png:** a small desk plant beside a neat stack of three cards with a check mark on the top card, sunrise shape behind it.
2. **tasks-empty.png:** an empty checklist clipboard with one unchecked box and a coffee cup beside it, relaxed and calm.
3. **dsa-empty.png:** a laptop showing a simple tree diagram (three connected nodes), with a small amber star above it.
4. **notes-empty.png:** a blank open notebook with a pen resting on it and a small lavender sticky note.
5. **contacts-empty.png:** two simple contact cards slightly overlapping, with a phone handset icon shape next to them.

If one comes out off-style, reply: "Same style as the earlier images, simpler shapes, fewer details."
